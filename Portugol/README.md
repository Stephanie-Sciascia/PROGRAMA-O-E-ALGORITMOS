# PORTUGOL
Este portfólio apresenta exercícios e atividades desenvolvidos utilizando Portugol para aprender conceitos básicos de lógica de programação.

## Objetivo

Praticar lógica de programação utilizando:
- Variáveis
- Entrada de dados
- Saída de dados
- Operadores matemáticos
- Operadores relacionais
- Estruturas condicionais
- `se` e `senao`
- Estruturas de repetição
- `enquanto`
- `para`
- Vetores
- Funções

## Organização

- exercicios/: exercícios desenvolvidos em Portugol
- condicionais/: atividades utilizando `se` e `senao`
- repeticao/: atividades utilizando estruturas de repetição
- vetores/: exercícios com vetores
- funcoes/: atividades utilizando funções
- projetos/: pequenos projetos desenvolvidos em Portugol
