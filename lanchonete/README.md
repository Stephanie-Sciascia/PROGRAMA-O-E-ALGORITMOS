# SISTEMA DE LANCHONETE

Este projeto apresenta um sistema de gerenciamento de uma lanchonete desenvolvido em Python.

## Objetivo

O objetivo do sistema é facilitar o controle de produtos, pedidos, estoque e vendas de uma lanchonete.

## Funcionalidades

O sistema permite:

- Cadastrar produtos.
Listar produtos e estoques.
- Fazer pedidos.
- Consultar pedidos realizados.
- Ver o produto mais vendido.
- Calcular o total de vendas.
- Exportar um relatório em CSV.
- Criar backup dos dados.

## Tecnologias utilizadas

- Python
- JSON — para salvar os produtos e pedidos.
- CSV — para gerar o relatório de vendas.

## Principais funções

O código possui funções para cada parte do sistema, como:

- register_product() — cadastra produtos.
- list_products() — mostra os produtos.
- make_order() — realiza pedidos e atualiza o estoque.
- list_orders() — mostra os pedidos.
- best_selling_product() — mostra o produto mais vendido.
- total_sales() — calcula o total vendido.
- export_csv() — cria o relatório de vendas.
- create_backup() — cria uma cópia dos dados.

Menu do sistema
- 1 - Cadastrar produto
- 2 - Listar produtos
- 3 - Fazer pedido
- 4 - Ver pedidos realizados
- 5 - Produto mais vendido
- 6 - Total vendido
- 7 - Exportar relatório
- 8 - Criar backup
- 9 - Sair

## Conclusão

O projeto foi desenvolvido para praticar Python e criar uma solução simples para o gerenciamento de uma lanchonete. Com ele, é possível controlar produtos, estoque, pedidos e vendas de forma organizada.
